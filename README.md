## Описание проекта

Веб-приложение для бронирования номеров в гостиничном комплексе. Позволяет гостям просматривать номера, выбирать даты и оформлять бронирование онлайн. Администраторы могут управлять номерами и подтверждать заселение гостей.

---

## Особенности

- Django + Python
- SQLite база данных
- Авторизация и регистрация пользователей
- Административная панель с кастомными действиями
- Валидация данных при бронировании
